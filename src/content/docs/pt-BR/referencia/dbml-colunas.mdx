## Sintaxe

Uma coluna por linha, dentro de `Table`:

```dbml
nome tipo [configuração, configuração, ...]
```

O nome aceita aspas duplas (`"preço total" decimal(10, 2)`). As configurações são opcionais, ficam entre colchetes e são separadas por vírgula.

## Tipos

O linter confere o tipo contra um catálogo. Um tipo fora dele é `Error`, e o linter sugere o mais parecido.

| Grupo | Tipos reconhecidos |
|---|---|
| Inteiros | `int`, `integer`, `tinyint`, `smallint`, `mediumint`, `bigint`, `int2`, `int4`, `int8`, `serial`, `smallserial`, `bigserial` |
| Numéricos | `decimal`, `numeric`, `real`, `float`, `float4`, `float8`, `double`, `money` |
| Texto | `varchar`, `char`, `character`, `nvarchar`, `nchar`, `text`, `tinytext`, `mediumtext`, `longtext`, `clob` |
| Lógicos e UUID | `boolean`, `bool`, `bit`, `uuid` |
| Data e hora | `date`, `datetime`, `datetime2`, `smalldatetime`, `time`, `timetz`, `timestamp`, `timestamptz`, `interval`, `year` |
| Estruturados | `json`, `jsonb`, `xml`, `array`, `enum`, `set` |
| Binários e rede | `bytea`, `blob`, `binary`, `varbinary`, `inet`, `cidr`, `macaddr` |
| Geometria e busca | `point`, `line`, `polygon`, `geometry`, `geography`, `tsvector`, `tsquery` |
| Enums do arquivo | o nome de qualquer `Enum` declarado, com ou sem schema (`status_pedido`, `financeiro.moeda`) |

A comparação não diferencia maiúsculas de minúsculas.

Parâmetros de tamanho vão entre parênteses: `varchar(120)`, `decimal(10, 2)`.

| Tipo | Regra do linter |
|---|---|
| `varchar`, `char`, `nvarchar`, `nchar` | Só 1 parâmetro. Tamanho 0 gera `Warning`. |
| `decimal`, `numeric` | Até 2 parâmetros (precisão, escala). Precisão 0 ou acima de 65 gera `Warning`. Escala maior que a precisão é `Error`. |
| Qualquer outro | Os parâmetros precisam ser números. |

Tipos com mais de uma palavra, como `double precision` ou `timestamp with time zone`, **não** são aceitos: use `double` e `timestamp`/`timestamptz`. Tipos de array com colchetes (`int[]`) também não: o `[]` é lido como um bloco de configurações vazio (`Warning`) e o tipo guardado é `int`.

## Configurações

| Configuração | Efeito |
|---|---|
| `pk` ou `primary key` | Chave primária. |
| `not null` | Coluna obrigatória. |
| `null` | Coluna explicitamente opcional. Combinada com `not null` ou `pk` é `Error`. |
| `unique` | Valor único. |
| `increment` | Autoincremento (`GENERATED BY DEFAULT AS IDENTITY` no PostgreSQL). |
| `default: valor` | Valor padrão. Aceita número (`0`), texto (`'BRL'`), `true`/`false` e expressão SQL entre crases (`` `now()` ``). |
| `note: 'texto'` | Nota da coluna. Veja [Notas](dbml-notas). |
| ``check: `expressão` `` | Restrição `CHECK`, com a expressão entre crases. Extensão aceita pelo produto. |
| `ref: operador alvo` | Relação inline para outra coluna. Veja [Relações](dbml-relacoes). |
| `delete: ação`, `update: ação` | Ações de integridade da relação inline. Valores: `no action`, `restrict`, `cascade`, `set null`, `set default`. |
| `fk` | Marca a coluna como chave estrangeira sem declarar o destino. Também é marcada automaticamente por qualquer `ref`. |

Qualquer outra configuração é `Error` (`Unknown setting`).

<Aviso tipo="cuidado">
Uma expressão crua em `default` ou `check` com `;` fora de aspas gera `Warning`, porque a expressão é exportada como está para o SQL.
</Aviso>

## Erro de tipo

```dbml
Table clientes {
  id bigint [pk]
  nome vrchar(120)
}
```

Diagnóstico: ``Unknown type `vrchar` on column `nome` (did you mean `varchar`?) ``. O arquivo `ref-colunas.erro.dbml` reproduz o caso.

## Outras mensagens do linter

| Mensagem | Causa |
|---|---|
| ``Column `x` has no type`` | Coluna sem tipo. |
| ``Duplicate column `x` in `tabela` `` | Nome repetido na mesma tabela. |
| ``Unknown setting `x` on column `y` (expected: pk, fk, not null, unique, increment, default, check, note, ref)`` | Configuração inexistente. |
| ``Conflicting constraints on column `x`: cannot be both `null` and `not null`/`pk` `` | `null` junto com `not null` ou `pk`. |
| ``Setting `default:` requires a value on column `x` `` | `default` sem valor. |
| ``Invalid referential action `x` for `delete:` (expected: no action, restrict, cascade, set null, set default)`` | Ação de integridade inválida. |
| ``Missing `]` to close settings`` | Faltou o colchete de fechamento. |
| ``Empty settings block `[]` on column `x` `` (aviso) | Colchetes vazios. |
| ``Scale (n) cannot exceed precision (m) in `decimal` on column `x` `` | Escala maior que a precisão. |
