## Sintaxe

```dbml
Project nome {
  database_type: 'PostgreSQL'
  Note: 'Texto descritivo do projeto.'
}
```

O bloco é opcional. Só o primeiro `Project` do arquivo conta.

## O que o produto usa

| Item | Efeito |
|---|---|
| `Note: '...'` | É a **nota do projeto**. Aparece no SQL exportado (como `-- Project: ...`) e na documentação gerada por `dbml docs`. |
| `database_type: '...'` | Aceito e preservado no arquivo, mas o produto **não o usa**. O dialeto do SQL exportado é escolhido na hora da exportação. |
| Outras chaves | Aceitas sem erro e ignoradas. |

## Observações

- O nome do projeto (`loja` no exemplo) não é exibido nem validado.
- A nota aceita aspas simples ou triplas. Veja [Notas](dbml-notas).
