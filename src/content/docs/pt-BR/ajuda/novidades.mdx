Esta página mostra o histórico de versões do DB Modeling, da mais nova para a mais antiga. O texto de cada versão vem do mesmo arquivo que alimenta a janela **Novidades** dentro do app, então os dois sempre dizem a mesma coisa.

Cada item é marcado como adicionado, melhorado ou corrigido, e vale para as modalidades que a versão cobre. Dentro do app Desktop, abra **O que há de novo** pela paleta de comandos (<Atalho acao="OpenPalette" />).

Para o histórico completo com binários e checksums, veja as [Releases no GitHub](https://github.com/dbmodeling/dbml/releases). Para atualizar, veja [Atualizações](atualizacoes).
