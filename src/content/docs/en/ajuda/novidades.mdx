This page shows the DB Modeling version history, newest first. The text for each version comes from the same file that feeds the **What's new** window inside the app, so the two always say the same thing.

Each item is marked as added, improved or fixed, and applies to the modalities the version covers. Inside the Desktop app, open **What's new** from the command palette (<Atalho acao="OpenPalette" />).

For the full history with binaries and checksums, see the [Releases on GitHub](https://github.com/dbmodeling/dbml/releases). To update, see [Updates](atualizacoes).
