## Syntax

```dbml
Project name {
  database_type: 'PostgreSQL'
  Note: 'Descriptive text for the project.'
}
```

The block is optional. Only the first `Project` in the file counts.

## What the product uses

| Item | Effect |
|---|---|
| `Note: '...'` | The **project note**. It appears in the exported SQL (as `-- Project: ...`) and in the documentation generated by `dbml docs`. |
| `database_type: '...'` | Accepted and kept in the file, but the product **does not use it**. The SQL dialect is chosen at export time. |
| Other keys | Accepted without error and ignored. |
