## Syntax

One column per line, inside `Table`:

```dbml
name type [setting, setting, ...]
```

The name accepts double quotes (`"preço total" decimal(10, 2)`). Settings are optional, go in square brackets and are separated by commas.

## Types

The linter checks the type against a catalog. A type outside it is an `Error`, and the linter suggests the closest match.

| Group | Recognized types |
|---|---|
| Integers | `int`, `integer`, `tinyint`, `smallint`, `mediumint`, `bigint`, `int2`, `int4`, `int8`, `serial`, `smallserial`, `bigserial` |
| Numeric | `decimal`, `numeric`, `real`, `float`, `float4`, `float8`, `double`, `money` |
| Text | `varchar`, `char`, `character`, `nvarchar`, `nchar`, `text`, `tinytext`, `mediumtext`, `longtext`, `clob` |
| Boolean and UUID | `boolean`, `bool`, `bit`, `uuid` |
| Date and time | `date`, `datetime`, `datetime2`, `smalldatetime`, `time`, `timetz`, `timestamp`, `timestamptz`, `interval`, `year` |
| Structured | `json`, `jsonb`, `xml`, `array`, `enum`, `set` |
| Binary and network | `bytea`, `blob`, `binary`, `varbinary`, `inet`, `cidr`, `macaddr` |
| Geometry and search | `point`, `line`, `polygon`, `geometry`, `geography`, `tsvector`, `tsquery` |
| Enums in the file | the name of any declared `Enum`, with or without schema (`status_pedido`, `financeiro.moeda`) |

Matching is case-insensitive.

Size parameters go in parentheses: `varchar(120)`, `decimal(10, 2)`.

| Type | Linter rule |
|---|---|
| `varchar`, `char`, `nvarchar`, `nchar` | Only 1 parameter. Length 0 gives a `Warning`. |
| `decimal`, `numeric` | Up to 2 parameters (precision, scale). Precision 0 or above 65 gives a `Warning`. Scale greater than precision is an `Error`. |
| Any other | Parameters must be numbers. |

Multi-word types such as `double precision` or `timestamp with time zone` are **not** accepted: use `double` and `timestamp`/`timestamptz`. Bracket array types (`int[]`) are not either: the `[]` is read as an empty settings block (`Warning`) and the stored type is `int`.

## Settings

| Setting | Effect |
|---|---|
| `pk` or `primary key` | Primary key. |
| `not null` | Required column. |
| `null` | Explicitly optional column. Combined with `not null` or `pk` it is an `Error`. |
| `unique` | Unique value. |
| `increment` | Auto-increment (`GENERATED BY DEFAULT AS IDENTITY` on PostgreSQL). |
| `default: value` | Default value. Accepts a number (`0`), text (`'BRL'`), `true`/`false` and a SQL expression in backticks (`` `now()` ``). |
| `note: 'text'` | Column note. See [Notes](dbml-notas). |
| ``check: `expression` `` | `CHECK` constraint, with the expression in backticks. An extension the product accepts. |
| `ref: operator target` | Inline relationship to another column. See [Relationships](dbml-relacoes). |
| `delete: action`, `update: action` | Referential actions for the inline relationship. Values: `no action`, `restrict`, `cascade`, `set null`, `set default`. |
| `fk` | Marks the column as a foreign key without declaring the target. Any `ref` also marks it automatically. |

Any other setting is an `Error` (`Unknown setting`).

<Aviso tipo="cuidado">
A raw expression in `default` or `check` containing `;` outside quotes produces a `Warning`, because the expression is exported as-is to SQL.
</Aviso>

## Type error

```dbml
Table clientes {
  id bigint [pk]
  nome vrchar(120)
}
```

Diagnostic: ``Unknown type `vrchar` on column `nome` (did you mean `varchar`?) ``. The file `ref-colunas.erro.dbml` reproduces the case.

## Other linter messages

| Message | Cause |
|---|---|
| ``Column `x` has no type`` | Column without a type. |
| ``Duplicate column `x` in `table` `` | Repeated name in the same table. |
| ``Unknown setting `x` on column `y` (expected: pk, fk, not null, unique, increment, default, check, note, ref)`` | Nonexistent setting. |
| ``Conflicting constraints on column `x`: cannot be both `null` and `not null`/`pk` `` | `null` together with `not null` or `pk`. |
| ``Setting `default:` requires a value on column `x` `` | `default` without a value. |
| ``Invalid referential action `x` for `delete:` (expected: no action, restrict, cascade, set null, set default)`` | Invalid referential action. |
| ``Missing `]` to close settings`` | The closing bracket is missing. |
| ``Empty settings block `[]` on column `x` `` (warning) | Empty brackets. |
| ``Scale (n) cannot exceed precision (m) in `decimal` on column `x` `` | Scale greater than precision. |
