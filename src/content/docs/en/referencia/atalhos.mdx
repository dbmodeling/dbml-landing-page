Every DB Modeling action has a keyboard shortcut where it makes sense, and appears in the **command palette** (<Atalho acao="OpenPalette" />). The in-app shortcut list opens with <Atalho acao="ShowShortcuts" />.

The table below is generated from the action catalog in the code. Shortcuts change with the modality and operating system: on macOS, `Ctrl` becomes `⌘`. The VS Code extension uses the same catalog as the Web.

<Aviso tipo="info">
Some actions exist in only one modality. For example, **Export .dbml** is Web-only, and **Check for updates** is Desktop-only. The table shows where each action applies.
</Aviso>
