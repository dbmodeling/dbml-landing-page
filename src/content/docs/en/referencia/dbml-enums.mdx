## Syntax

```dbml
Enum [schema.]name {
  value
  value [note: 'text']
  "value with space"
}
```

One value per line. Values with spaces or special characters use double quotes.

| Item | Effect |
|---|---|
| `value` | An enum value, in the written order. |
| `[note: '...']` | Value note. |
| `schema.name` | Enum inside a schema. |

## Use as a type

The enum name is the column type. With a schema, write the qualified name.

```dbml
Table pedidos {
  status status_pedido [not null, default: 'pendente']
  moeda financeiro.moeda
}
```

An enum `default` goes in single quotes, as text.

## Common error: undeclared enum

```dbml
Table pedidos {
  id bigint [pk]
  status status_pedido
}
```

Diagnostic: ``Unknown type `status_pedido` on column `status` ``. Declare the `Enum` (anywhere in the file) or use a known type. The file `ref-enums.erro.dbml` reproduces the case.

## Notes

- The enum can be declared before or after the tables that use it.
- In SQL export for PostgreSQL, the enum becomes `CREATE TYPE ... AS ENUM` (with `CREATE SCHEMA IF NOT EXISTS` when there is a schema).
- Other settings in the enum header are accepted and ignored.
